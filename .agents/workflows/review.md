# Code Review Workflow

## 1. Inspect Git

Check:

- Current branch
- Git status
- Complete diff

## 2. Understand

Understand the purpose of the changes.

Inspect surrounding code when necessary.

## 3. Review

Analyze:

- Correctness
- Security
- Reliability
- Performance
- Maintainability
- Testing

## 4. Verify

Run relevant tests and checks where appropriate.

## 5. Report

Produce a structured review.

Do not modify the code unless explicitly asked.
